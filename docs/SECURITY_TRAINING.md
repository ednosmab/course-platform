# Programa de Treinamento de Segurança

## Público-Alvo

- Desenvolvedores (técnico)
- Administradores da plataforma (operacional)
- Equipe de suporte (atendimento)

## Conteúdo

### Módulo 1 — Engenharia Social (todos)
- Reconhecer phishing, spear-phishing
- Anexos suspeitos e links enganosos
- Política de mesa limpa (clean desk)
- Procedimento para reportar tentativas

### Módulo 2 — Desenvolvimento Seguro (devs)
- OWASP Top 10: XSS, SQLi, CSRF, IDOR
- Revisão de código com foco em segurança
- Uso correto de SAST (CodeQL/Semgrep)
- Sanitização de entrada com Zod + DOMPurify
- RLS e JWT no Supabase

### Módulo 3 — Operações (admin + suporte)
- Política de senhas fortes e MFA
- Identificação de atividade suspeita nos logs
- Procedimento de resposta a incidentes
- Não compartilhar credenciais

### Módulo 4 — LGPD/GDPR (todos)
- O que são dados pessoais
- Direitos dos titulares
- Bases legais para processamento
- Procedimento de vazamento de dados

## Periodicidade

| Tipo | Frequência | Formato |
|------|-----------|---------|
| Onboarding | Antes do primeiro acesso | Assíncrono (leitura + quiz) |
| Reciclagem | Anual | Workshop 2h |
| Simulado de phishing | Semestral | Campanha automatizada |
| Pós-incidente | Após SEV-0/1 | Reforço específico |
