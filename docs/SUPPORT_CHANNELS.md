# Canais de Suporte

## Canais Disponíveis

| Canal | Público | SLA primeira resposta | Horário |
|-------|---------|----------------------|---------|
| **E-mail** | Todos | 24h úteis | Seg-Sex 9h-18h |
| **Chat in-app** | Alunos e admins | 5 min (horário comercial) | Seg-Sex 9h-18h |
| **Central de Ajuda** | Todos | Autoatendimento | 24/7 |
| **Ticket (admin)** | Admins curso | 4h úteis | Seg-Sex 9h-18h |
| **Canal crítico** | Incidentes SEV-0/1 | 15 min | 24/7 |

## Categorias de Ticket

| Categoria | Descrição | Encaminhamento |
|-----------|-----------|---------------|
| `bug` | Erro de funcionamento | Time de engenharia |
| `feature` | Sugestão de melhoria | Product manager |
| `billing` | Problemas de pagamento/fatura | Financeiro |
| `content` | Problema com conteúdo de curso | Equipe de conteúdo |
| `account` | Problemas de acesso/perfil | Suporte nível 1 |
| `security` | Vulnerabilidade ou incidente | Tech Lead (prioridade máxima) |

## Reportar Problemas

### Usuários
- **Bug:** Enviar email para `suporte@mosaico.com` com:
  - Descrição do problema
  - Prints/vídeo se aplicável
  - Navegador e versão
  - Passos para reproduzir
- **Segurança:** security@mosaico.com (criptografado com PGP)

### Pesquisadores de Segurança
- security.txt disponível em `/.well-known/security.txt`
- Política de disclosure coordenada (90 dias para correção antes da divulgação)
- Bug bounty: a definir

## Métricas de Qualidade

| Métrica | Alvo |
|---------|------|
| CSAT (satisfação) | >= 85% |
| FCR (resolvido no primeiro contato) | >= 70% |
| SLA de primeira resposta | >= 90% dentro do prazo |
| Tempo médio de resolução (SEV-0) | < 2h |
| Tempo médio de resolução (SEV-1) | < 8h |
