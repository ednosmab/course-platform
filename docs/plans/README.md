# Path Canónico de Planos

Todos os planos formais do projecto vivem aqui.

## Convenção de nome

`YYYY-MM-DD-<slug-curto>.md`

## Quando arquivar

- Planos com ≥ 5 steps
- Planos que tocam ≥ 2 ficheiros
- Planos que requerem G-01 explícito
